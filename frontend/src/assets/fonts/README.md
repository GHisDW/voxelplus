# Bundled fonts

Both families are variable WOFF2 (latin subset) files served locally so the
launcher renders identically offline and inside the production CSP (which no
longer allows third-party font hosts).

| File | Family | Weights | Upstream |
|---|---|---|---|
| `outfit-latin.woff2` | Outfit | 300–800 | https://github.com/Outfitio/Outfit-Fonts |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | 400–600 | https://github.com/JetBrains/JetBrainsMono |

Both fonts are licensed under the **SIL Open Font License 1.1**; the full
license texts are included next to the font files (`OFL-Outfit.txt`,
`OFL-JetBrainsMono.txt`).
